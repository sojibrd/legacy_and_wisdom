# Legacy & Wisdom — 10-Stage Personal Life Roadmap

জীবনের দীর্ঘমেয়াদি রোডম্যাপ — ১০টা stage-এ ভাগ করা, প্রতিটায় Technical Skills, Financial Management, Health ও Family Responsibility-র ভারসাম্য রেখে।

- **লাইভ সাইট:** https://sojibrd.github.io/legacy_and_wisdom/
- **স্ট্যাক:** Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, Static Export → GitHub Pages

## লোকাল ডেভেলপমেন্ট

```bash
npm install
npm run dev
```

ব্রাউজারে [http://localhost:3000](http://localhost:3000) খুলুন।

## স্ট্যাটিক বিল্ড যাচাই

```bash
npm run build
```
